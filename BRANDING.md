# taskbloc

The approved identity is the supplied three-block logo with a lowercase navy wordmark.

- Teal: `#0bb2a8`
- Pink: `#ff2160`
- Yellow: `#ffcc00`
- Navy: `#121e3d`

`public/taskbloc-logo.svg` is a scalable recreation of the supplied reference, with an embedded Inter wordmark font. `public/favicon.svg` uses the three-block symbol. Both have transparent backgrounds.

Use **taskbloc** for visible product names. Existing `taskline` source paths, environment variables, API routes and browser storage keys remain compatible with saved tasks and existing integrations.
